# Icon Library

Allen (2026-10-22): "use this persons profile's inventory for decals for icons whenever we need them for now. he has a bunch of icons that are available and apply for our game." Source: **VectorIcons** (Roblox user 5246503529), [decal inventory](https://www.roblox.com/users/5246503529/inventory#!/decals). The Hotbar's backpack icon already comes from this creator ([[Art/UI Design#Backpack (2026-10-21)]]).

**How to use one:** the numbers below are **decal** ids. An `ImageLabel` needs the decal's image id: in Edit, `game:GetService("InsertService"):LoadAsset(<decal id>)` and read the `Decal.Texture` inside (or use the image id already recorded in a row's note). Record the image id here when an icon goes into the game.
