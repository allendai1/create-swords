# UI Review 2026-10-26

Every StarterGui screen, captured in Edit at Studio's desktop size for Allen to critique ("Can u take photos of all our UIs so i an critque and change"). Lists the code fills at runtime are filled here with copies of the GUI's own templates, so the text in them is template placeholder (every slot an Iron Ingot, every letter from Takeda); the picker is drawn by the real ItemPicker code. The HUD shows under station HUDs because the originals stayed on. Not captured: phone size, the grind map and strike ring (empty until code places them), the tutorial spotlight (sized at runtime). Images: `References/UI Review 2026-10-26/`.
