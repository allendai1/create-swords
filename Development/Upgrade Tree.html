Upgrade Tree

Drag a pad onto the pad it should wait for. Drag empty space to move around.

Columns count the buys a pad waits behind: Start is open on a new plot, +1 needs one pad bought first, and so on. A pad with two lines in waits for both. Crew hires cost gems as well as coins. Cart Capacity and Speed levels, gem upgrades and decorations are bought in their windows and are not shown. Times are the median of 150 simulated free players from run prices-recheck-2026-11-10, so they describe the tree before any rewiring. Rewiring is kept in this browser only: Copy changes and send the list to Claude to apply it to the game and the sim.
