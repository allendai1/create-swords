## Keep the vault current

1. **GDD = intended behavior.** Update it when a design choice is agreed, with a dated explanation in Decisions Log.
2. **Current Status = build snapshot.** Replace stale summaries; keep details in linked technical notes and session history. Distinguish reported results from fresh verification.
3. **Roadmap = remaining work.** Remove completed work from active tasks once evidence is recorded; keep historical task snapshots in Archive.
4. **Sessions = history.** Append daily activity here, not to Current Status. Earlier entries describe what was true at the time.
5. **Art/research = proposals or references.** Use a clear status and link to the chosen direction or build record.
6. Use unique note names, vault-relative wiki links, and the note properties `type`, `status` where useful, and `updated`. Keep folder depth shallow.
